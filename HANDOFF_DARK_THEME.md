## Откуда дизайн

Прототип Claude Design "JBJ Platform" (палитра, Montserrat, компонентная
раскладка) лежит в `design/project/JBJ Platform.dc.html` — исходный

отбора) сделаны по отдельным скриншотам-референсам от пользователя
(не из этого файла) — см. коммиты 07.09 ниже.

## Ключевые паттерны, если продолжаете в том же стиле

- **Тёмный layout** — `mx-[calc(50%-50vw)] -my-6 min-h-[100dvh] bg-night-bg
  font-night text-night-text`, внутри `<DarkTopNav />` + контент +
  `<BottomNavGate />` (мобильный, через `Suspense`). Смотрите
  `src/app/compete/layout.tsx` как образец.
- **Список тёмных маршрутов** — `src/lib/dark-routes.ts`
  (`DARK_ROUTE_PREFIXES` + `isDarkRoute()`), используется в
  `HeaderVisibility`/`FooterVisibility`. Добавляя новый тёмный раздел —
  впишите префикс туда же.
- **Наведение на ссылки** — глобальный фикс уже есть
  (`.font-night a:hover` в `globals.css`), но если ссылка должна на
  hover менять цвет НЕ на белый — добавляйте `hover:text-night-*` явно
  (специфичность утилитного класса-модификатора выше).
- **Общие светлые компоненты** (`Card`, `Badge`, `Tag`, `Button`,
  `ui/field.*`) НЕ трогаем напрямую — они шарятся со светлыми страницами
  (`/moderation`, `/dancers` раньше, и т.д.). Переопределяем цвета через
  `className` на конкретной странице (`cn()`/tailwind-merge это
  поддерживает).
- **Табличный список с drag-and-drop** — `CategoryList.tsx` (Pointer
  Events: `setPointerCapture` на хендле `⠿`, `onPointerMove` ищет строку
  под курсором по `getBoundingClientRect()`, при отпускании считает
  order = позиция и шлёт `PATCH` только для сдвинувшихся строк). Такой же
  подход можно применить, если понадобится перетаскивание где-то ещё
  (например, будущий admin-раздел "Судьи").

## ВАЖНО: подводный камень с dev-сервером

Когда удаляете файл компонента, который Next.js dev-сервер уже успел
скомпилировать, webpack-кэш иногда не подхватывает удаление и падает с
500 ("Failed to read source code... os error 2") — **нужен полный
перезапуск dev-сервера** (`preview_start` заново), просто hot-reload не
помогает.
